# 数学证书与时间上界复核

`reproduce_math.py` 提供问题一正确舍入证书、指定晚期初值区间证书和全初态时间上界的统一入口。运行位置可以是任意目录，`--out` 应为支撑材料目录之外的一个新目录。所有计算输出写入该目录。

## 覆盖范围

| 材料 | 对应结论 | 包内内容 |
| --- | --- | --- |
| `certificates/` | 问题一 37,800 个温度值和 17,357 个含水率值的正确舍入 | 解析比较算法、谱根、向外区间、参数、原附件、来源绑定及独立核验记录 |
| `evidence/endpoint/` | 表 12 的两类晚期根区间 | P23 从 206880 s、P4 从 183900 s 开始的精确 binary64 节点、Radau 多项式、区间常数、权重、半离散管和连续样条屏障证书 |
| `code/extensions/endpoint/` | 晚期误差控制算法及数值验证流程 | 区间运算、局部误差管、样条屏障、来源核验和完整数值调度源码 |
| `new_audit_branch/PROJECT/extension_physics_audit/boundary/math_upper/` | P23 的 332 h、P4 的 763 h 充分时间上界 | 有理向外算术生产器、参数与摘要、逐箱检查器、条件定理推导 |
| `new_audit_branch/PROJECT/extension_physics_audit/boundary/math/`及`boundary/code/` | 临界及以上边界情景的有限时间不可达性 | 累计下屏障生产器、四小时中心下界、尾段正幅度、条件推导与独立审查记录 |

问题一其余 20,443 个含水率值的正确舍入仍属于证书覆盖范围之外。晚期证书对应指定节点形成的初值问题，结论范围限于该晚期窗口。332 h、763 h 是所声明 B0 一维模型及解的正则性前提下的充分上界；正文的 57.4796 h、51.0970 h 是数值终点结果。

## 快速核验

在支撑材料目录执行：

```text
python -B 验证材料/reproduce_math.py --mode verify --out ../数学证据检查
```

此模式核对全部数学材料的文件哈希、问题一全部 75,600 个向外区间、谱根存储记录、晚期初态和数学源码绑定，以及上界摘要的整数小时取整。

累计下屏障的来源绑定、四小时中心下界及尾段严格正幅度也在该模式中核对。

它还从证书保存的十六进制字段恢复全部 75,600 个选定 binary64 数值，逐项比较 `results/result1.xlsx` 的四位小数，生成 `selected_fields_from_certificate.npz`。该文件是根据证书字段建立的数值容器，具有单独记录的 SHA-256；这一步属于数据恢复与比对。

## 晚期证书重新计算

```text
python -B 验证材料/reproduce_math.py --mode endpoint-weighted --out ../晚期半离散复核
python -B 验证材料/reproduce_math.py --mode endpoint-first-slab --out ../晚期连续首段复核
python -B 验证材料/reproduce_math.py --mode endpoint-full --out ../晚期连续全窗口复核
```

`endpoint-weighted` 对两问完整晚期窗口重新计算加权区间管、根区间和横截性，比较每个证明数值。`endpoint-first-slab` 检查两问各自第一时间段的连续空间屏障。`endpoint-full` 重新计算两问全部时空区间，耗时较长。三种模式均由包内精确初态出发。

`proof_manifest.json`、两个连续证书内的源码绑定以及实际装载的数学模块共同约束证明来源。`bundle_inventory.json` 描述当前小包文件，`bundle_inventory_original.json` 和 `inventory_provenance.json` 保存包装清单的来源记录。

## 全初态上界重新计算

```text
python -B 验证材料/reproduce_math.py --mode upper-full --out ../全初态上界复核
```

该模式重新计算 P23 的 65,536 箱、P4 的 32,768 箱，检查导出 CSV 的 SHA-256 与证书记录是否一致，执行全部有理算术验收，再以独立 100 位 Decimal `exp/ln` 逐箱交叉核验。100 位计算是独立数值交叉检查，严格向外保证来自原有理算术及余项界。约 51.6 MB 的逐箱 CSV 写入指定输出目录，交付包内保留生产器与校验依据。

## 问题一解析重建

需要安装 `python-flint==0.9.0`，并具备 NumPy、SciPy、openpyxl。版本要求见支撑材料根目录 `requirements.txt`。`--arb-runtime` 可显式指定包含 python-flint 的导入目录。

```text
python -B 验证材料/reproduce_math.py --mode q1-runtime --out ../解析运行库检查
python -B 验证材料/reproduce_math.py --mode q1-roots --out ../谱根重建
python -B 验证材料/reproduce_math.py --mode q1-regenerate --out ../问题一解析区间重建
```

`q1-runtime` 装载冻结数学函数并核验精确初等值；`q1-roots` 重建全部谱根与排零记录；`q1-regenerate` 根据包内附件、精确参数和证书数值字段，重新计算全部解析区间，并比较原精确投影和紧凑证书的 SHA-256。完整解析模式耗时较长。

本目录各模式均为数学证据处理与解析计算。四问主 PDE 的重新求解由支撑材料根目录说明中的主程序入口承担。本次实际完成的核验范围见 `数学复核结果.json`。

## 临界情景下屏障重新计算

```text
python -B 验证材料/reproduce_math.py --mode lower-full --out ../临界情景下屏障复核
```

该模式从两份附件及模型配置重新计算全部下屏障常数，核对科学字段与绑定记录的一致性，并用独立90位 Decimal 表达式检查指数包围、充分速率条件和尾段初始顺序。P23、P4四小时中心下界分别向下显示为0.725099、0.925801；尾段正幅度分别为0.4063243793、0.5568514880。条件推导见 `boundary/math/累计水分下屏障_推导与范围.md`。
