# Q1 内层含水率的解析舍入候选

本目录针对原 B0 问题1，不修改模型或原输出。目标是直接从比较原理证明一部分题定值舍入为 2.5500。正式验收还需要独立重放，以及适用于初始 Robin 不相容情形的存在唯一性依据；当前所有 `partial_candidates_accepted` 均为 false。

## 模型及常数屏障

令 x=r/R，F(C)=∫从C0到C exp(-q/s)ds，U=F(C)，G=F⁻¹，K=R hm/Dp，则

\[
 U_t=a(U)\Delta_rU,\quad a(U)=D_p e^{-q/G(U)}/R^2,
 \quad U_x(1,t)+K[G(U(1,t))-C_e(t)]=0.
\]

这里 Δr=∂xx+x⁻¹∂x，轴心按二维圆盘内部点解释。输入在 [0,1800] 上分段线性；实际核过全部31个结点及其含义包围，得到 0<C*≤Ce≤C0。常数 C*、C0 分别为子、上解，故在适用比较原理的解类内 C*≤C≤C0。

任一候选下势 W 可在 W>U 的潜在违反区域使用：此时 W>U≥F(C*) 且 W≤0，因此 G(W) 在合法正区间内。W≤F(C*) 的区域自动不会违反。无需把折角函数 max(F(C*),W) 误称经典 C² 屏障，也无需在 W 很负时计算不存在的正逆值。

## I0 指数屏障

取严格正数 λ，常数界

\[
 a_m\ge D(C_0)/R^2,\quad B\ge K(C_0-C_*),
 \quad 0<\beta_m\le K/F'(C_0),
\]

并设

\[
 H_\lambda=\lambda I_1(\lambda)+\beta_m I_0(\lambda),\qquad
 W(x,t)=-{B e^{a_m\lambda^2t}I_0(\lambda x)\over H_\lambda}.
\]

I0、I1 在正轴为正，I0 为 x² 的整函数，ΔrI0(λx)=λ²I0(λx)，且 ∂xI0(λx)|x=1=λI1(λ)。这些恒等式来自 [NIST DLMF §10.25](https://dlmf.nist.gov/10.25) 和 [§10.29](https://dlmf.nist.gov/10.29)。

在合法正域中 a 随 U 递增，W≤0，因此

\[
 W_t-a(W)\Delta_rW=(a_m-a(W))\lambda^2W\le0.
\]

由于 F'>0、F''≥0，G 为凹函数，G(W)≤C0+W/F'(C0)。记 β0=K/F'(C0)，则表面

\[
 W_x+K(G(W)-C_e)
 \le K(C_0-C_e)-B e^{a_m\lambda^2t}
 {\lambda I_1+\beta_0 I_0\over\lambda I_1+\beta_m I_0}
 \le B(1-e^{a_m\lambda^2t})\le0.
\]

W(x,0)≤0=U(x,0)，轴心导数为零。若 v=W-U 为正，则因 ΔW=λ²W≤0，

\[
 v_t-a(U)\Delta_rv
 \le[a(W)-a(U)]\Delta_rW\le0.
\]

Robin 非线性严格递增，同样排除表面正最大值。故 W≤U。这里比较的是连续原始初值，不要求 W 在初始时刻等于原初值，也未改成一个后期初值问题。

λ 的每一个严格正值都给出合法上界。程序对每个题定点用非严格优化提供 λ 猜测，然后将其冻结为精确有理数，用 Arb 向外计算完整表达式。因此正确性不依赖优化器找到最优值。

## 与 erfc 启动层界合并

actual_02 保留另一解析界 W=-A w((1-x²)/2,t)，其中 w 为半轴热通量响应。对每个输出时刻 t，以

\[
 \kappa>\big[a_m\sqrt{\pi t}+\sqrt{a_m^2\pi t+a_m}\big]^2
\]

保证整个 [0,t] 上 a_m-κ+2a_m√(πκt)<0；实际逐时刻向外验证。Arb 直接包围 exp、erfc，不以浮点样本替代界。两个合法下界可逐点取更强者，因为它们都包住同一个原解。

## 每值的舍入门

令 L=2.54995。先对整个参数含义范围包围 F(L)，得到上端 fhi。若势下降上界 δ 满足 -δ>fhi，则严格推出 C>L。又 C≤C0<2.55005，故唯一 HALF_UP 舍入为 2.5500。

进一步在 C≥L 后，由 F'(C)≥F'(L) 得 C≥C0-δ/F'(L)；程序使用初值下端、F'(L)下端及 δ 上端，并与 L 取最大。这是逆函数的单调性和积分下界，未对累计量误差求导。

所有物理常数含 model.json 的原十进制及 binary64 两种值，环境含原 XML、binary64、最短往返十进制值；半径位置复用已独审的 Q1 热证书位置包围。没有加入测量误差或参数辨识不确定性。
