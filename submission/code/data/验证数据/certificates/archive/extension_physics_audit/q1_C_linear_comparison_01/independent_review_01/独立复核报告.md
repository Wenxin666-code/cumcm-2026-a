# 常数 Robin 热比较场的独立复核

实际完成且通过：`computed_02/summary.json`。在此前独立证明的 Q1 正解存在唯一性、常数上下界及局部裁切比较基础上，本次合并界支持 17,357 个题定水分值正确舍入为 2.5500，含前 3 个半径列的全部 1–1800 s 时刻。其余 20,443 个 Q1 水分值尚未证明。没有启动原非线性 PDE，没有更换正式数组或工作簿，也没有将部分认证写成四问全体完成。

## 理论核查

本比较场满足 Wt=amax ΔW、Wn+βW=−B、W(0)=0，β=βmin>0。V=1+βW/B 为齐次 Robin 热半群作用于常数 1。由正性、序保持和 1 为超解，0≤V≤1 且 V(t+h)≤V(t)，因而 W≤0、Wt≤0、ΔW≤0。真实正差接触区域有 a(W)≤amax；G 凹，G(W)≤C0+W/F′(C0)。β≤K/F′(C0)、B≥K(C0−Ce_min) 分别保证内部与实际非线性 Robin 下解条件。截断处不作经典求导，沿用已独审的接触区域论证。

常数 1 的径向模态系数为 A_n=2β/[J0(λ_n)(λ_n²+β²)]，λ_n J1(λ_n)=β J0(λ_n)。因此 W=−(B/β)[1−Σ A_n J0(λ_n x) exp(−amax λ_n²t)]。这和先前温度斜率势 P 的展开不同：本次尾系数只有 1/λ 衰减，没有额外 1/(aλ²)。根交错与 |A_n|≤4β/λ_n 的证明沿用已独立审查的正 Robin 谱论证，对本次正 β 同样适用。

取 N=768、b=2N−1=1535，t≥1，完整尾部的统一界为

\[
 \sum_{n>N}|A_n|e^{-a\lambda_n^2t}
 \le\frac{4\beta}{b}\frac{e^{-ab^2}}{1-e^{-4a(b+1)}}.
\]

理由是 λ_n>2n−3；相邻平方下界增量至少 4(b+1)，而倒数因子单调减小。代码采用的正 a 是人为选择且严格包住物理扩散的常数 amax，本尾界针对该比较场，不能换成任意更大 a 或移用于非线性真解的谱。

## 实际核验范围

独立验证器没有导入原 `certify_linear_lower.py` 执行。使用已冻结独立热证书验证器的基本有理数与根记录检查函数，并核其 SHA；原根生成器与 SciPy 猜根均未调用。

- 重新计算 768 个 J0 根与 768 个 Robin 根的端点异号、整个盒内非零导数、交错身份；19,627 个无零区间逐个重算，准确衔接从 0 到最后 J0 根的全覆盖，无跳段漏根。
- 尾界以 256 位重新求得完全相同准确端点，再用 384 位的等价表达式验证原上端向外。谱和尾界约 2.6996220765704544e-14；随后乘 B/β 进入势降界，不能把这个谱和界直接标成水分 C 误差。
- 37,800 个有限和加尾后的区间全部重算，准确有理端点与原记录一致；逐行核时空身份、与前批取 min、势到 C 的转换、唯一 bin 标记和已独审源值记录。
- 另取 47 个时间截面（含早期、每列唯一区间的前后临界时刻和 1800 s），共 987 值，直接计算 exp(−aλ²t)，不使用原逐秒递推；所有区间与原区间相交，唯一 bin 分类一致。
- 计数准确重建：17,357 个唯一 bin，32,822 个位置的线性势界较前批更小；前一批 15,122 个值均保留在合并结果中。准确最小 C bin 余量记录在 summary，位置为 1458 s、半径序号 5（0.5 cm）。
- 删除排零区间、重复根索引、错误唯一 bin、篡改 C 区间、把尾界置零的 5 个实际夹具均拒绝。全部绑定源码与产品运行前后 SHA 一致。

`computed_01` 保留一个验证器准备阶段失败：原产品清单使用 Windows 反斜杠，初版只按正斜杠比对名称，故拒绝“missing product”；当时没有完成数值复核。`verify_preflight_01.py` 保留那版源。当前验证器仅规范化用于名称集合的路径表示，实际路径约束和全部 SHA 门保留；`computed_02` 为上述完整成功运行，约 10.59 s。
