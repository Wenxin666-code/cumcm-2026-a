# 数值验证程序与结果

本目录包含一维三次 GLL 独立求解、二维 Robin 与移动 Neumann 解析验证、非线性双场制造解，以及二维完整重构场比较程序。数值误差对照、保存多项式的向外包围和连续 PDE 误差证明分别解释。

## 二、运行方法

在本目录执行下列命令。`python` 指安装了根目录 `requirements.txt` 所列依赖的解释器。`--out` 指向整个支撑材料目录之外的工作路径；每组完整求解应指定一个新的工作子目录。

```text
python -B reproduce_numerics.py readback --out D:/数模复核/数值读回
python -B reproduce_numerics.py checks --out D:/数模复核/方法检查
python -B reproduce_numerics.py fem --out D:/数模复核/一维GLL
python -B reproduce_numerics.py mms --out D:/数模复核/二维制造解
python -B reproduce_numerics.py plan-2d --out D:/数模复核/二维全场
```

- `readback` 校验9份原始数组哈希、有限性、其内含参考场的误差，并核对32例制造解摘要和源码身份。
- `checks` 还实际执行一维制造解/Bessel模态检查、双三次 Bernstein 包围代数检查、双线性完整场差检查。
- `fem` 从原数组内含参考字段建立查询数据，保持原64/128/256单元和时间容差，完整求解9个GLL问题；每个问题继续采用各自的原始参考场与共同查询时刻，并与原GLL数组比较。该步骤生成新的求解记录与 `fem_recompute.json`。
- `mms` 完整执行两组各16例的二维解析/制造解，输出全部场数据、逐例记录及验收摘要。
- `plan-2d` 写出 `production_plan.json`，其中 `commands` 依次列出完整二维P1生产、前置检查与比较命令。计划本身只写命令；执行这些命令会生成较大的逐秒完整场文件。

对主程序产生的未舍入FV数组，采用以下入口重新配对一维GLL。P1提供含21个指定半径的 `solution.npz`，P23/P4提供含21个材料位置的 `samples.npz`。程序只选择完全共同保存时刻和已有材料位置。

```text
python -B reproduce_numerics.py compare-1d --fv-p1 D:/主计算/q1/solution.npz --fv-p23 D:/主计算/p23/samples.npz --fv-p4 D:/主计算/q4/samples.npz --out D:/数模复核/FV与GLL
```

## 三、验证范围

本目录所附记录包含9个一维GLL问题的完整重新求解、16例二维解析验证、16例非线性制造解，以及代数与保存数组读回检查。重新求解环境为 Python 3.13.9、NumPy 2.1.3、SciPy 1.15.3、openpyxl 3.1.5；主结果的指定生产依赖见支撑材料根目录。

一维重新求解与保存GLL数组的最大温差约为 `3.49e-8 K`，最大含水率差约为 `7.76e-10`。一致性检查阈值为 `1e-7`；这一阈值约束两次数值求解间的差异。二维解析与制造解的32例均通过各自程序内置的误差及收敛检查。

表11最终FV配对数据的完整来源摘要随包保存；直接重算该配对需要主求解器输出的未舍入FV轨迹。二维1800秒大网格全场比较提供完整生成和复核入口，所附此次验收记录覆盖制造解与比较算法检查。保存的双三次多项式包围并不等同于非线性连续PDE的严格误差界。
