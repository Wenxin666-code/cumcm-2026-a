# 晚期连续空间条件包围：数学对象与证明条件

实际区间核为 `code/continuous_late_meanvalue.py`，以 `continuous_late_spline.py` 的C2重构取代历史Hermite试验，并调用 `continuous_late_barrier.py`、`endpoint_study.py` 与 `decimal_bounds.py`。原主算例求解器及数组未改。是否完成、管是否闭合、事件是否包住分别以每问 `continuous_certificate.json` 为准；首段试算不能代替全窗口证书。汇总结果由 `summarize_endpoint.py` 在所有必要完成标志均通过后生成。

## 被定义的条件问题

在保存的晚期窗口起点重新定义连续初态：温度精确等于恒定环境温度，水分是通过保存节点值的唯一夹持 C2 三次样条，轴心导数为零，表面导数精确满足非线性 Robin 条件。该条件温度在热方程中保持常数；不是将原全程温度的浮点近零差视为数学上的零。

对归一化半径 x=r/R(t)，水分满足

\[
 C_t=L_t(C)=R(t)^{-2}\{D(C)(C_{xx}+C_x/x)+D_C(C)C_x^2\},\qquad
 B_t(C)=D(C)C_x+R(t)h_m(C-C_e)=0\quad(x=1).
\]

每段时间内节点轨迹为连续拼接的 Radau 三次多项式。样条 q(t,x) 的中心导数为零，表面导数取精确解析函数 `-R hm (q_s-Ce)/D(q_s)`。对该斜率使用 Taylor 多项式加经 Cauchy 估计的数值及时间导数余项，余项通过样条线性影响函数传播，不能仅采用截断后的斜率。夹持样条二阶导数由严格对角占优三对角方程唯一确定，用 44 位 Decimal 向外区间 Thomas 消元包住全部系数。节点处 q、q_x、q_xx 连续，因此 D(q)q_x 连续，没有遗漏界面分布源。时间节点允许 q_t 跳跃，比较逐段延续。

首单元 q=A0+A2 v²+A3 v³、x=hv，故 q_x/x=(2A2+3A3v)/h²，径向 Laplace 为 (4A2+9A3v)/h²；轴心直接使用该有限极限。

## 空间连续屏障

固定解析正权重 w(x)=exp(6(x²−1))，取 U±=q±a(t)w。此处 w 是连续解析函数，与半离散证书中的固定 binary64 节点权重是两个不同的证明对象。对所有时间和空间区间、|δ|≤cap，核验 q+δw>0、D>0。记 l=w_x/w=12x、K=Δw/w=24+144x²，沿同一个标量 δ 的导数为

\[
 \frac{\partial_\delta L_t(q+\delta w)}{w}
 =R^{-2}\{D_C(U)(\Delta q+\delta wK)+D(U)K
 +D_{CC}(U)(q_x+\delta wl)^2+2D_C(U)(q_x+\delta wl)l\}.
\]

以区间上界 μ≥0 及 η≥sup|q_t−L_t(q)|/w 构造 a'=η+μa 的上包络，并检查整个时间段 a<cap。实现采用 `(a0+ηh) exp(μh)`，它向上包住常系数精确增长式。表面需独立核验

\[
 \partial_\delta B_t(q+\delta w)
 =D_C(U)(q_x+12\delta)+12D(U)+Rh_m\ge0.
\]

因此 U+ 的内部剩余量和 Robin 剩余量非负，U− 非正。中心对称条件自动满足。标量正扩散方程的首次接触论证可分别应用于二者；它不要求、也不宣称原热湿两分量系统合作。适用范围是该指定晚期初态的标量一致抛物问题之正则解。D 的非线性、时间变化半径、所覆盖局部域和边界符号均需要实际区间检查，不能省略。

其正则性和比较适用条件可进一步用 Kirchhoff 变换说明。令 F'(C)=D(C)>0、u=F(C)，则

\[
 u_t=\frac{D(F^{-1}(u))}{R(t)^2}\Delta u,\qquad
 \partial_nu+R(t)h_m\{F^{-1}(u)-C_e\}=0.
\]

正屏障将C限制在严格正的紧区间，因此D及其需要的导数光滑有界，扩散一致为正；边界函数对u的导数 Rh_m/D 严格为正。圆盘边界光滑，指定C2夹持样条精确满足初始Robin条件；轴心没有一次项，三次径向项仍属于 C^{2,α}（任意0<α<1），不会在轴心产生奇异源。在此相容初值与紧正状态区间内，局部正则解的标量比较适用，正屏障使解留在相同一致抛物区间，支持在所证有限窗口上的延拓。这里描述的是指定条件初值问题，不是对原全程初边值不相容层的正则性证明。

实际两问晚期窗口内半径均为正常数。`certificate_guards.json` 与证书中的 `guards` 保存各接口半径的精确分数和全接口一致性；来源快照另绑定全部半径节点。一般光滑、严格正的时间变半径并不破坏上述变换，但不得把本次恒半径结果默认为已核验所有其他运动规律。

若另外核验 q_x/x+12 cap w≤0，则 U+ 最大值在轴心。U− 的轴心值给真实全场最大值的下界。最终事件区间还必须核验轴心下屏障在左端以前保持高于阈值（由各段 q_t(0)<0 与 a 非减保证），及右端全场上屏障低于阈值；不能只凭两个采样时刻或未经证实的单调性作二分认证。实际入口在进入区间核前执行 `certificate_guards.audit` 并断言通过，全窗口轴心及各节点多项式时间导数严格为负、原报告时刻处于窗口内、所有接口的完整样条唯一性连续均已单独核验。证书保存这些实际guard，不只在文字中假设。

精确阈值采用十进制0.15。参数、附件插值节点、网格及所计算尾均值则视为冻结binary64的精确实数（来源manifest给出float.hex）；本证明不包含题面十进制转二进制误差或尾均值的计算舍入误差。

## 尚未认证的必要环节

原问题从 t=0 到晚期窗口的连续初态误差未被包住；原全程温度并非被证明精确恒温。若放宽为小温差，水分方程出现含温度梯度的 D_T T_x C_x 项，仅有温度幅值上界不够，还需实际可验证的梯度/耦合稳定性界。空间与时间网格加密、独立有限元对照可作为后验支持，不能替代这两个缺失的严格上界。即使晚期条件屏障完成，也不能升级成原全程耦合连续 PDE 的无条件终点认证。
