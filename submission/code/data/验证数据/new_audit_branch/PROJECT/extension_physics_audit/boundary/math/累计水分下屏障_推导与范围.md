# 临界及以上边界情景的累计水分下屏障

本说明对应论文“临界及以上情景的有限时间不可达性”。计算常数由 `../code/certify_mass_lower_barrier.py` 生成，精确参数与向外区间见 `results/mass_lower_constants.json`。统一复核入口为支撑材料中的 `验证材料/reproduce_math.py --mode lower-full`。

## 模型与比较条件

采用正文 B0 无潜热一维固定域或定长仿射收缩域，环境和半径延拓遵循题目附件及模型配置。假设解在正系数区域存在，具有连续初始迹，跨输入断点连续，并在每段正时间具有比较原理所需的经典及轴正则性。

令 `x=r/R(t)`、`y=x²/2`，累计水分为

`M(y,t)=∫₀ʸ C(√(2z),t) dz`。

其方程为 `M_t=(2y/R²)D(T,M_y)M_yy`；轴端 `M(0,t)=0`，表面满足 `M_t+(h_m/R)M_y=(h_m/R)C_eq`。

设 `v=Hy+U(t)y(1-ay)`，其中 `a=1/2`、`U'=−λU`。在 `v−M−εt` 的正最大点，两者的一阶导数相同，因而扩散率的含水率自变量相同；内点由二阶导数符号排除正最大值。轴端由累计量为零排除，外端由动态 Robin 边界及正系数排除。该比较仅需扩散率在所比较正域为正。

## 下屏障充分不等式

有 `v_y=H+U(1−2ay)`、`v_yy=−2aU`。若 `H≤C_eq`，且

`λ ≥ 4a D_upper / [R_lower²(1−a/2)]`，

`λ ≥ (2 h_m_upper/R_lower)(1−a)/(1−a/2)`，

则 `v_t−(2y/R²)D(T,v_y)v_yy≤0`，并满足动态边界的下屏障不等式。这里的 `D_upper` 只要求包围屏障斜率处的扩散率。程序根据无源热方程的上界 `T≤323.4 K` 及屏障斜率 `0<v_y≤2.55` 构造该扩散率界；所有充分常数均经有理向外运算核验。

## 前四小时与尾段衔接

当 `α≥α_crit=0.15/C_room,tail` 时，题给尾环境值使 `α_crit>3`，而全部观测环境含水率大于 `0.0196`。因此前四小时的有效边界大于 `0.0588`，可取 `H=0.05`、`U(0)=2.49`。初始下屏障位于均匀含水率2.55的累计量之下。

程序取 P23 的半径下界为0.02 m；P4在前四小时取0.0147 m，尾段取0.0119 m。线性半径插值与规定末半径延拓使这些下界有效。

| 模型 | 四小时中心含水率下界（向下显示） | 尾段正幅度 V₀ |
| --- | --- | --- |
| P23 | 0.725099 | 0.4063243793 |
| P4 | 0.925801 | 0.5568514880 |

在四小时接点，`M/y≥H+(1−a/2)U(14400)` 对全部正 `y` 成立。尾段取 `H=0.15`，并使 `0.15+V₀` 低于该累计平均下界，因此尾段下屏障的初始顺序成立。尾段采用相应半径下界和同样的充分速率条件，得到

`C(0,t) ≥ 0.15+V₀ exp[−λ_tail(t−14400)] > 0.15`。

这里通过 `lim(y→0+)M/y=C(0,t)` 得到中心界。中心含水率高于阈值，已足以排除全域严格干燥；任意有限实数时间的指数项均为正。前四小时的下屏障同样保证中心始终高于0.15。

## 运算与范围

生产器使用精确 Fraction 运算、带显式余项的指数 Taylor 包围以及交错级数交叉检查。`lower-full` 重新生成全部常数，逐项比较科学字段，并以独立90位 Decimal 表达式核对扩散率、四小时指数幅度、充分速率条件和尾段初始顺序。

该结果是上述 B0 模型和解类的条件不可达性结论。四问主数值轨迹、潜热模型及二维模型分别采用各自的计算和验证。本说明按论文公式及随包常数整理；归档的独立审查脚本和审查记录保留各自来源身份。
