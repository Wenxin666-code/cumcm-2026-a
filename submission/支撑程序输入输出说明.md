# 支撑程序用途、内容与输入输出

本文中的路径以支撑材料目录为基准。命令在该目录执行；`python` 指已安装 `requirements.txt` 所列依赖的解释器。主计算通过 `--work` 指定包外工作目录，数学和数值验证通过 `--out` 指定包外输出目录。每组完整验证宜采用独立的新目录；数学入口要求输出目录尚未存在。

四问主程序的共同调用方式如下。将题号替换为1、2、3或4即可选择相应任务。

```powershell
python -B code/问题1.py --mode plan --work ../计算工作
python -B code/问题1.py --mode run --work ../计算工作
python -B code/问题1.py --mode check
python -B code/问题1.py --mode plot --work ../计算工作 --figure-profile production
```

`plan`展示任务，`run`执行求解及导出，`check`核对五份主源码和已交付结果的哈希，`plot`执行相应绘图流程。问题2和3共享同一条固定域轨迹。完整科研绘图入口为：

```powershell
python -B code/公共依赖.py --plot-paper --work ../计算工作 --figure-profile production
```

## code/问题1.py

用途与内容：组织问题1预热阶段的计算与结果导出。内容包括基准计算、磁盘轨迹计算、必要对照及结果表生成。

输入：附件1中的环境数据、附件2及共享model.json；新建计算目录。

输出：预热阶段温度与含水率轨迹、关键对照记录及result1.xlsx。

绘图内容与数据生成：先调用问题1主流程生成预热温湿轨迹和高分辨率径向剖面，积分得到四环带净失水占比；补算均匀N=10240网格的B1表面潜热情景，再逐秒计算两种气相含水率解释下的条件露点和蒸汽压比。环境输入图的终点标记依赖问题2/3和4，缺少时自动调用这两条主流程。输出f02_inputs、f03_q1、vapor_compatibility各自的PDF与PNG。

## code/问题2.py

用途与内容：组织问题2固定几何域下的变物性热湿传递全过程。内容包括基准轨迹、径向细化、终点候选与结果导出。

输入：两份题目附件和共享model.json；可复用同一计算目录中已完成的问题2/3共同任务。

输出：全过程温湿轨迹、细网格与终点资料、关键结果核验及result2.xlsx。

绘图内容与数据生成：调用或复用本次问题2/3主计算的细网格场和终点，自动整理前三小时温度、全程径向最大含水率、0.15阈值及代表时刻剖面。输出f04_p23.pdf与PNG；采用本次计算出的终点标记。

## code/问题3.py

用途与内容：组织问题3全域干燥终点判定。内容包括调用或复用问题2/3共同计算、提取终点资料并导出第三问结果。

输入：两份附件、共享model.json以及共同计算轨迹；没有轨迹时先执行共同求解。

输出：全域干燥终点及其温湿场、结果核验记录和result3.xlsx。

绘图内容与数据生成：与问题2共用同一求解轨迹、数据整理和f04_p23图；缺少同一输入及源码对应的计算时，自动调用问题2共同主流程。输出f04_p23.pdf与PNG。

## code/问题4.py

用途与内容：组织问题4耦合半径收缩的温湿传输计算。内容包括收缩主算例、终点细化、严格阈值数值判定与导出。

输入：环境与半径观测附件、共享model.json和新计算目录。

输出：半径与温湿演化轨迹、干燥终点、关键对照资料和result4.xlsx。

绘图内容与数据生成：调用问题4主流程生成收缩域温湿场、半径和终点；实际求解N=640的11个单因素情景及2个非对角物性—几何算例；调用收缩运动学程序，求解β=-1、-0.5、0、0.5、1五组N=2560情景并提取最大含水率历史和事件终点。输出f05_q4、f06_factorial、nonaffine_kinematics各自的PDF与PNG。

## code/公共依赖.py

用途与内容：提供四问共享的附件读取与插值、物性计算、径向网格、固定域及收缩模型、时间积分、轨迹记录、任务复用、工作簿导出和关键核验。七张论文图的绘制函数、公共样式、图专用计算及数据整理集中实现在本文件中；深度研究通过适配器调用其科学计算接口。

输入：主程序或研究适配器传入的参数、附件、模型配置及相应轨迹。

输出：求解状态与数值场、过程记录、导出工作簿或核验报告；具体输出由调用任务决定。

论文绘图输入：附件1、附件2，code/config下的主模型和收缩运动学配置，以及code/data/latent中的潜热参考表和来源说明。

数据生成：generate_paper_figure_data组织主模型、B1潜热、气相诊断、物性—几何与边界情景、收缩运动学计算；build_and_plot_paper将生成的数据交给七图绘制函数。数据存于包外计算目录的paper_figures：runs保存径向场与终点，studies保存情景终点和四格结果，kinematics保存五组运动学情景与最大含水率历史，vapor.npz保存气相诊断数组。

计算重用：程序根据源码、输入、配置、数值环境和输出哈希复用已完成任务，自动求解缺失任务。输入、源码或已完成输出发生变化时，程序提示使用新的计算目录。续算读取相应轨迹、检查点和完成记录。

绘图输出：七张图各自的PDF、PNG及数据来源记录，默认保存于工作目录的figures。图中的场分布、诊断量和终点来自计算结果。图专用生产计算采用N=640的假设情景、N=2560的运动学情景和N=10240的潜热情景；主模型采用对应生产设置。

配置与环境：默认production用于论文计算；smoke用于低网格全时程接口测试，结果保存于独立的paper_figures_smoke和figures_smoke目录。运行依赖见requirements.txt，绘图使用SimHei（黑体）字体。

## 验证材料的目录和数据关系

验证程序由七份科学计算文件和一份公共接口组成。公共接口定位包内资源、校验数据、记录当前源码，并通过普通模块导入取得已有主模型和研究实现。数据目录中保存证据所需的参数、精确数组和来源记录。

阅读时先看各文件开头的流程说明，再看相应模型类与`main`入口；同目录的`验证公共接口.py`集中处理路径、JSON/CSV/压缩日志读写、数组加载、来源身份、数据校验和已有模型接口。

| 文件 | 负责的验证 | 直接复用的实现 |
| --- | --- | --- |
| `code/问题一舍入验证.py` | 温度与部分含水率的正确舍入、谱根隔离、解析区间和数值字段对表 | 共享文件与来源记录接口；严格谱算法独立实现 |
| `code/晚期区间验证.py` | 精确晚期初值、半离散误差管、连续样条屏障、指定时刻查询和局部轨迹生产 | 主模型构造、物性及数值右端 |
| `code/时间界限验证.py` | 332 h/763 h充分时间上界、累计下屏障及条件不可达性 | `code/深度研究/连续PDE.py`的有理向外算术 |
| `code/一维GLL验证.py` | 一维三次GLL独立弱式、九组求解及与FV场配对 | 数据和记录接口；弱式、物性保留独立实现 |
| `code/二维验证.py` | 解析/制造解、二维物理计算、全场比较及生产计划 | `code/深度研究/二维模型.py`的空间模型、时间推进、场记录和多项式区间算法 |
| `code/输入与假设验证.py` | 环境平台识别、24种单因素情景、物性与几何交叉及精度比较 | 主模型、边界、物性、事件求解和移动半径采样 |
| `code/一维FV验证.py` | 一维有限体积制造解、守恒结构及固定半径退化检查 | 主模型的径向与收缩求解接口 |


## code/问题一舍入验证.py

输入：`数据/certificates`内的谱参数、向外区间、存储谱根和来源记录，以及附件1和`results/result1.xlsx`。解析重建需python-flint 0.9.0。

输出：`q1_verification.json`、选定数值字段容器；相应模式还输出谱根、精确解析区间和紧凑区间文件。

| 模式 | 工作内容 |
| --- | --- |
| `readback` | 以标准库读取证据，核对75,600个区间及来源身份。 |
| `verify` | 读回证据，并从十六进制字段建立数值容器，与result1逐项配对。 |
| `runtime-check` | 装载Arb并检查数学核心与参数。 |
| `direct-check` | 直接求和完整斜率跳历史，复核1,365个温度值和987个含水率值的解析区间。 |
| `reconstruct-roots` | 重新隔离谱根，执行排零与来源核对。 |
| `regenerate-exact` | 重新生成完整解析区间及紧凑投影，并与证据比较。 |
| `rebuild-compact` | 读取`--temperature-log`和`--moisture-log`给出的两份原始完整精确gzip日志，先核对原日志SHA，再重建紧凑区间。 |

问题一另外20,443个含水率值处于该正确舍入证书的覆盖范围之外。

## code/晚期区间验证.py

输入：`数据/evidence/endpoint`中的精确binary64节点、参数、时间多项式及区间证书。`--case`选择p23、q4或both；自产数据可通过`--bundle`指定。

输出：区间验证报告、误差管、根区间或指定时刻含水率上界；`produce`写局部轨迹与后续验证所需数据。

| 模式 | 工作内容 |
| --- | --- |
| `verify` | 检查数据、节点连接、初态和证据来源，以及已存误差管与连续证书的一致性。 |
| `model-bindings` | 用公共依赖构造主模型，逐常量、逐节点及半径窗口核对晚期快照。 |
| `arithmetic` | 检查Decimal向外四则、指数界、样条和均值计算。 |
| `uniform`、`refined`、`weighted` | 计算对应半离散误差管；weighted采用包内权重并比较完整晚期窗口证据。 |
| `continuous-first`、`continuous-full` | 计算连续空间屏障的首个时间段或整个窗口。 |
| `query` | 用`--time`查询指定十进制秒数处的上界，省略时采用报告时刻。 |
| `produce` | 从`--runs`中的主模型轨迹生成晚期局部积分数据，主模型和右端直接复用公共依赖。 |

自产快照的refined模式通过`--uniform-base`指定uniform输出，query通过`--certificates`指定continuous-full输出。`--runs`中的p23、q4子目录各含`internal.npz`和`endpoint.json`。

uniform、refined、weighted分别记录实际闭合与事件状态；Q4的已有uniform方案未通过，程序保存结果并以非零状态结束，正权方案由weighted执行。

`--method`选择meanvalue、spline、hermite或adaptive屏障；`--cap`及时间/空间细分参数用于明确指定的数学实验。首段检查对应首段，晚期初态与题给初态的误差关系需分别解释。

## code/时间界限验证.py

输入：主模型配置、题目两份附件、已有上下界摘要；公共有理算术来自`code/深度研究/连续PDE.py`。

输出：`verification.json`；upper同时生成P23和P4的逐箱CSV。默认上界计算包括有限形状筛选、标量分箱细化、精确有理审查和独立100位Decimal逐箱检查。

| 模式 | 工作内容 |
| --- | --- |
| `verify` | 核对输入与来源身份，检查已有上界的整小时取整。 |
| `checks` | 核对模型前提、输入节点和有理向外算术。 |
| `upper` | 完整计算充分时间上界；`--gap`默认0.0001，约束标量积分间隙。 |
| `lower` | 完整计算累计下屏障的扩散率、衰减率、4h中心下界与尾段正幅度，并以90位Decimal交叉核验。 |

332h、763h为B0一维模型及正则性条件下的充分上界。下屏障证明在环境放大系数不小于临界值时，任何有限时刻的中心仍严格大于0.15。高精度Decimal提供独立交叉检查，严格向外保证来自有理算术与显式余项界。

## code/一维GLL验证.py

输入：模型配置、两份附件、9份GLL数组及内含参考字段。`compare`另需主程序生成的未舍入FV数组。

输出：原始数据读回报告、方法检查、独立GLL场及重新求解差值；配对模式输出共同时间和共同材料位置上的FV/GLL误差、位置和来源记录。

| 模式 | 工作内容 |
| --- | --- |
| `readback` | 检查9份数组身份、有限性、内含参考场差值和配对摘要。 |
| `checks` | 进行一维制造解、模态、空间离散方法检查，以及守恒观察器的精确多项式测试。 |
| `solve` | 按`--cases`与`--elements`运行独立GLL；默认P1/P23/P4各64、128、256单元。 |
| `compare` | 直接配对`--fv-p1`、`--fv-p23`、`--fv-p4`与所附GLL数组，使用完全共同时间与已有节点。 |
| `compare-rounding` | 对已生成的三组网格/容差轨迹比较终点、共同时间场及论文表格的逐格四位舍入变化。 |

`compare-rounding --runs`接收JSON路径清单，包含`production`、`p23`、`q4`三项；路径相对于该JSON文件。production保存论文轨迹，后两项保存各案例的粗网格、细网格及细网格较严容差轨迹。该模式输出`global_refinement_comparison.json`与`global_refinement_roots.csv`，固定域按材料位置配对，收缩域保留原表格的固定物理半径列。

FV数组路径示例：

```powershell
python -B code/一维GLL验证.py compare --fv-p1 ../计算工作/runs/q1_disk/full/solution.npz --fv-p23 ../计算工作/runs/endpoint/p23/finest_candidate/p23/samples.npz --fv-p4 ../计算工作/runs/endpoint/q4/finest_candidate/q4/samples.npz --out ../FV_GLL配对
```

P1数组包含`t_s`、`r_m`、`T_K`与`C`；P23/P4包含`t_s`、`xi`、`T_K`与`C`。独立弱式和物性实现是该验证与主有限体积程序相互对照的基础。

## code/二维验证.py

输入：题目附件、模型参数、制造解配置或指定的粗细网格完整场目录。空间离散、时间推进、热量审计及场记录由`code/深度研究/二维模型.py`提供。

输出：读回与方法检查、32例制造解结果、物理场轨迹、连续重构场比较报告、可执行计划及汇总。

| 模式 | 工作内容 |
| --- | --- |
| `readback` | 核对既有解析/制造解摘要和输入来源。 |
| `checks` | 运行双三次Bernstein、双线性完整场差、共同时间及事件差等代数检查。 |
| `audit-check` | 检查独立时空求积与BDF连续重构的离节点事件。 |
| `mms` | `--family`选择analytic、nonlinear或all；all为两组各16例。 |
| `physical` | 用`--engine fe/fv`运行实际二维模型；定时使用`--end`，寻找干燥事件使用`--event --horizon`。 |
| `compare` | 比较`--coarse`与`--fine`的完整连续重构场，`--times`和`--gap`指定比较范围及细化目标。 |
| `compare-baseline` | 用`--run`指定二维场、`--baseline`指定一维主程序目录，比较有符号含水率差、极值位置及中心最大值。 |
| `backend-check` | 执行18项短算，比较二维生产后端及前置算例。 |
| `fv-analytic` | 执行12项有限体积解析算例，比较空间网格与时间容差。 |
| `heat-check` | 比较4类场景的热量观察器，`--end`默认1800 s。 |
| `fixed-heat` | 用`--run`指定实际轨迹，检查固定J情景的热量恒等式。 |
| `plan` | 写出二维生产与比较计划，执行任务所需参数明确列出。 |
| `execute-plan` | 执行`--plan`指定的计划。 |
| `summarize` | 汇总`--runs`列出的实际记录；`--plan`核对完整矩阵，`--criteria`指定FV精度准则。 |

`compare-baseline`读取P23/P4一维目录的`internal.npz`和`metadata.json`；Q1直接读取`grid_profiles.npz`（t_s、r_m、T_K、C）及其原生metadata。程序核对双方实际模型、相关附件哈希、物性、共同时间半径与定长几何；Q1固定半径模型按其实际输入绑定配置与附件1。FV的有符号差覆盖双线性重构的全空间极值；FE的有符号差限定于节点，连续最大值是否位于中心另用Bernstein界判断，不确定时明确记录。

二维完整场生产可能产生较大的轨迹文件。计划记录、实际执行、制造解验证和连续PDE误差证明各有相应的范围字段。直接复算论文表11最终FV配对及二维大网格差，需要先生成对应未舍入完整场。

## code/验证公共接口.py

提供`DATA`、`SUPPORT`等资源路径；`read_json`、`write_json`、`write_csv`、`write_jsonl_gz`处理记录，`load_npz`加载数值数组，`sha256`与`source_hashes`计算文件身份，`audit_header`构造运行信息，`run_cli_modes`按任务表调用入口。`prepare_output`保护输入目录，`verify_data`检查数据集合与文件哈希。`science(name)`取得主模型科学分区，`research(name)`取得已有研究模块；`source_identity`记录当前验证代码、主模型与数据清单身份。

该文件承担接口和运行记录，科学计算分别由七类验证及其明确调用的主模型或研究模块完成。


## code/输入与假设验证.py

输入：环境与半径附件、主模型配置，以及按当前源码生成的情景轨迹。环境平台选择只读取温度观测，各物理情景保留原观测节点并指定其后的延拓。底层物性、模型、推进与采样由公共依赖提供。

| 模式 | 工作内容 |
| --- | --- |
| `environment` | 末段平台的分段最小二乘识别、BIC样式描述性评分及规则敏感性。 |
| `checks` | 前缀和代价与直接最小二乘对照、小数据全分割穷举、摄氏/开尔文一致性、边界缩放与半径尾段核验。 |
| `plan`、`run` | 24种单因素情景，默认56次空间/时间精度计算；`--grids`和`--cases`选择子集。 |
| `factorial` | 两种物性×两种几何的交叉项计算及四格分解，读取同目录中的对角基准。 |
| `extra` | P4两个基准的N1280较严时间容差计算。 |
| `summarize` | 从`--runs`读取完整情景目录，核对62次事件计算、比较情景效应，延续细网格状态并核验干侧报告时刻。 |

示例在支撑材料目录执行：

```powershell
python -B code/输入与假设验证.py checks --out ../假设方法检查
python -B code/输入与假设验证.py run --out ../假设情景计算
python -B code/输入与假设验证.py factorial --out ../假设情景计算
python -B code/输入与假设验证.py extra --out ../假设情景计算
python -B code/输入与假设验证.py checks --out ../假设情景计算
python -B code/输入与假设验证.py summarize --runs ../假设情景计算 --out ../假设情景汇总
```

run、factorial、extra和checks可在同一个包外情景目录中依次运行。每个计算记录绑定当前源码、参数、附件与数值数组；完整汇总核对默认矩阵，子集计算用于明确指定的实验。末段识别属于描述性模型，物性切换、环境延拓与边界缩放属于确定性假设，经验网格/容差差用于数值对照。

## code/一维FV验证.py

输入：主模型的三组物性、独立解析制造解和测试参数。输出：空间与时间精度比较、径向算子守恒及固定半径退化报告。该验证检验一维有限体积实现；GLL文件检验独立有限元弱式，两者分别提供数值证据。默认命令为`python -B code/一维FV验证.py --out ../一维FV检查`，采用20、40、80三个网格，完成三物性共9组制造解、最细P4时间容差加密和结构检查；`--grids`与`--config`可指定测试参数。

验证数据中的推导与运行记录保留生成时的路径语境。当前程序路径与调用方式以`code/验证程序说明.md`及《支撑程序输入输出说明》为准。
